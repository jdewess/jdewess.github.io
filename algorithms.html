Artifact Description

This artifact is a C++ and OpenGL program I created in CS 330. It displays a 3D desk scene with a counter, laptop, book, mug, mouse, and lamp. The project uses basic meshes, textures, materials, lighting, and camera controls to build the scene.

Reason for Selecting and Improving the Artifact

I picked this artifact because the scene worked, but the original code used a separate block of drawing commands for every object. That approach was fine for a small class project, but it would become harder to manage as more objects were added.

For the enhancement, I created a SCENE_OBJECT structure and stored the objects in a vector. I also used unordered maps for textures, materials, and object names. This changes common searches from O(n) to an average of O(1).

A stable O(n log n) sort groups similar objects before the program uses one O(n) loop to render the scene. I also added checks for duplicate object names and the texture limit.

Course Outcomes

This enhancement met the main outcome I planned for algorithms and data structures. I selected a vector for moving through the objects in order, hash maps for faster lookup, and stable sorting to organize the objects before rendering.

There is a tradeoff because the indexes use extra memory and must be rebuilt after sorting, but the new design is easier to expand. The work also supports the outcome about using appropriate computing tools and techniques. My written explanation supports the communication outcome.

Reflection

The biggest thing I learned was that data structures can improve organization as well as speed. Moving the object settings into one structure made the rendering process much shorter and separated the scene data from the drawing logic.

One challenge was making sure every original transformation, texture, material, and mesh type was transferred correctly. I also had to rebuild the name index after sorting because the objects changed positions in the vector.

Before the final ePortfolio submission, I planned to run the enhanced project in the complete CS 330 Visual Studio environment, compare it with the original, and make any changes recommended by my instructor.

The portfolio ZIP contains the original and enhanced C++ source, shaders, and Visual Studio project files. The large texture image files were unchanged by this enhancement and are not duplicated in the portfolio download.
