Artifact Description

The artifact I selected is my Weight Tracker Android app from CS 360. I originally made it with Kotlin, Android Studio, and SQLite. Users can create an account, sign in, record their weight, set a goal, and view their progress. I picked this project because the database already worked, but it was basic enough that I could make a noticeable improvement.

Reason for Including the Artifact

I included this app because it shows how a database works inside a real mobile application. In the original version, the app stored users and weight entries, but it replaced the old goal every time the user entered a new one.

For this enhancement, I upgraded the database to version 3 and added goal history, date-range queries, summary statistics, and indexes for user-and-date searches. The dashboard now shows the number of entries, average weight, and total change. The goal screen also shows recent goals instead of only the current one. I included a migration so older information is kept when the database is upgraded.

Course Outcomes

This enhancement mainly supports course outcome four because I used Android and SQLite tools to add useful features to the app. It also supports outcome three because I had to think about query organization, database indexes, and the trade-off between better performance and added complexity.

I addressed outcome five by using parameterized queries, user-specific filters, foreign keys, and validation rules. These changes help protect each user's information and keep invalid data out of the database. My narrative and code documentation also help support the communication outcome.

Reflection

The biggest thing I learned is that improving a database involves more than adding another table. I had to make sure the database, service classes, and screens all worked together.

The hardest part was planning the migration because I did not want older users to lose their saved information. I also learned why indexes are helpful when the app repeatedly searches by user and date.

I added tests for migrations, account separation, goal history, date ranges, and summary calculations. Overall, this enhancement made the app more useful and gave me a better understanding of database design, upgrades, and security.
